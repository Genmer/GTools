# GTools 四期 UI 复刻规范（对齐 uTools 视觉语言）

> 本文档是四期「按 uTools 页面样式复刻」的唯一视觉锚点。参考图在 `docs/design/refs/`：
> - `calc-paper-utools.png` — uTools「计算稿纸」官方界面（图1，calc 插件像素级参考）
> - `shell-compare.png` / `shell-compare-1400.jpg` — 左 GTools 现 shell vs 右 uTools shell（图2，shell 与通用列表参考）
>
> 所有颜色仍一律取 `src/renderer/src/assets/themes.css` 的 CSS 变量（三主题 light/dark/glass 联动），本文新增的 design token 一律以 CSS 变量形式并入该文件，禁止硬编码色值。

## 1. 全局视觉语言（从图2 右侧提炼）

uTools 的整体气质：**窗口更宽、圆角更大、投影更柔、层级用「背景色差」而非边框表达、内容留白充足、字号层级分明**。

### 1.1 窗口与层级
- 主窗宽度 **800px**，高度自适应内容：常规 560px；空态由渲染层实测内容自然高度上报（主进程夹紧 260–720px）。
- 窗口圆角 **12px**（主进程 BrowserWindow 的 roundedCorners + CSS 配合）。
- 投影（主进程设置，浅色主题）：大而柔，`0 12px 40px rgba(0,0,0,0.18)`；深色主题减弱为 `0 12px 32px rgba(0,0,0,0.45)`。
- 层级表达：搜索框区背景比窗体深一档；列表区与窗体同底；空态功能宫格区以 `--bg-raised` 大圆角面板承载；脚注区透明底。**少用 1px 边框，用底色差**。

### 1.2 Design tokens（并入 themes.css）
```css
:root {
  /* 字号 */
  --fs-input: 15px;   /* 搜索框输入 */
  --fs-title: 14px;   /* 列表主文/插件标题 */
  --fs-sub: 12px;     /* 次要说明 */
  --fs-foot: 11px;    /* 脚注/快捷键提示 */
  /* 圆角 */
  --r-lg: 12px;  /* 窗口级/大卡片 */
  --r-md: 8px;   /* 按钮/输入控件/网格单元 */
  --r-sm: 6px;   /* 小徽标/输入框内元素 */
  /* 间距 */
  --sp-1: 4px; --sp-2: 8px; --sp-3: 12px; --sp-4: 16px; --sp-5: 24px;
  /* 阴影（浅色主题） */
  --shadow-window: 0 12px 40px rgba(0,0,0,0.18);
  --shadow-pop: 0 4px 16px rgba(0,0,0,0.12);
  /* 交互态 */
  --hover: rgba(0,0,0,0.05);      /* dark/glass 用 rgba(255,255,255,0.08) */
  --active-row: var(--accent-dim);
  /* 滚动条（§1.7 半透明；dark/glass 用白色叠层）：插件页原生 thumb 与 shell 滚动悬浮指示条共用 */
  --scrollbar-thumb: rgba(0,0,0,0.2);
  --scrollbar-thumb-hover: rgba(0,0,0,0.32);
}
```

### 1.3 搜索框（shell.SearchBox 重点改造，对照图2）
- 高度 **52px**（含上下内边距，整体紧凑不臃肿），外距：距窗顶 12px、左右 16px。
- 背景 `--bg-raised`（浅色 #F7F7F9 档），**无外边框**，自身圆角 `--r-lg`（融入窗口大圆角时可上直角下圆角）。
- 左侧放大镜图标 18px（`--fg-dim`），与文字间距 10px；输入字号 `--fs-input`。
- 右侧功能键：清除按钮（有内容时出现），hover 才显色。（uTools 搜索框内的插件过滤指示在 GTools 不适用：进入插件关键字态后搜索框整体隐藏、由插件标题栏表达，见 §1.7。）
- 输入光标色 = `--accent`。

### 1.4 结果列表（shell.ResultList，对齐空态 9 列图标网格统一语言）
- 结构：顶部「搜索结果」小标题 + 命中数量标签；下方为 **9 列图标网格**（与空态应用栏完全同构），单项由 40px 图标（应用真图标/字母块/插件 emoji）+ 居中文名（匹配高亮 `--accent`）组成。
- 详情提示：底部浮出当前选中条目的完整名称与功能副标题（`{{ title }} · {{ subtitle }}`），解决九宫格文本截断问题，信息与美感兼备。
- 键盘导航：上下键跨行跳 9 格，Tab / Shift+Tab 在网格内前后逐格切换；选中态高亮 `--active-row`，即时自动滚入视口。
- 窗口高度：同样由实测自然高度驱动，按行数自适应贴合（1 行约 200px、2 行约 280px、3 行约 360px），无死板大面积空白。
- 无结果态：居中线性放大镜图标 + 引导文案与拼音/首字母提示。

### 1.5 空态布局（uTools 图标网格形态，五期改版，对照 refs/empty-grid-utools.png）
- 搜索为空时从上到下：**第一行「最近打开」** → **应用栏**；整体仍坐落于 `--bg-raised` 圆角 `--r-lg` 面板内（图标块反向取 `--bg` 保层级），面板与搜索框同以左右 16px 对齐。
- 「最近打开」：一行最多 **9 个图标**（圆角方块 ~40px，无文字标签，hover 提示名称），记录最近打开的应用与最近使用的插件条目（按时间混合、去重）；行上方小标题 `--fs-foot` 灰字「最近打开」。
- 应用栏：本机应用 **9 列网格**（图标 ~40px + 名称 `--fs-foot` 一行截断），**置顶应用排最前**并带角标（左上小图钉/圆点），hover 浮出操作（打开/置顶/取消置顶），区域可滚动。
- 点击图标 = 打开应用（宿主应用服务负责），回车同点击；键盘导航扁平序覆盖两区（最近行 → 应用网格）。
- 兜底：宿主应用枚举为空（如 Windows 未实现/扫描失败）时回退为插件网格（4 列旧形态）。
- 空态窗口高度 = 内容实测自然高度（折叠态约 292px：最近行 + 应用 1 行，网格贴底收尾、无脚注栏）；抽屉展开后随行数加高，超 720px 转为面板内滚动（此时才启用 32px 底部渐隐 mask 与 36px 底留白，恰好放满时贴底 4px）。
- shell 滚动容器（空态/结果列表）隐藏原生滚动条槽（经典槽位会占宽使面板右缘与搜索框错开 10px）：滚动反馈为滚动期间容器右缘 4px 半透明悬浮条（不占位、不贴边）；容器底部 32px 渐隐收尾，替代内容被视口硬切（对齐 uTools 面板底部渐隐）。

### 1.6 脚注（快捷键提示条）
- 高 30px，透明底，左「↑↓ 选择 · Enter 打开 · Esc 返回」右「设置入口图标」，文字 `--fs-foot` + `--fg-dim`，hover 图标转 `--fg`。（Tab 切换未实现，不写进提示文案。）**空态隐藏脚注栏**（对齐 uTools 网格贴底收尾），空态的设置入口 = 搜索框右侧齿轮。

### 1.7 插件页容器（shell.PluginViewHost）
- 进入插件后搜索框隐藏，顶部改为**插件标题栏**：高 40px，白底（`--bg`），左返回箭头 + 插件名 + 插件图标，右侧插件自有工具位；底部 1px `--border` 分隔。
- 插件内容区：背景 `--bg`，内边距 16px；超出滚动，滚动条细（6px）半透明（插件页保留原生细滚动条，与 shell 的悬浮指示条方案不同属有意取舍：插件内容区多为局部滚动、对齐敏感度低）。
- 支持深度链接：`index.html#plugin=<id>&q=<query>` 直达某插件视图（截图脚本与自动化都依赖此入口）。

## 2. 通用控件规范（全部插件页面复用）

- **主按钮**：高 32px，内边距 0 14px，圆角 `--r-md`，底色 `--accent` 白字；次按钮透明底 1px `--border` 边框；危险按钮 `--danger`。禁用态降透明度 0.45。
- **输入控件**：高 32px，底色 `--bg-raised`，聚焦 2px `--accent-dim` 外圈（无硬边框）。
- **下拉选择**：原生 select 美化或自绘，高度 32px，弹出层 `--shadow-pop`。
- **工具栏**：高 40px，透明底贴内容顶，图标按钮 28×28，hover `--hover` 圆角 `--r-sm`。
- **空态**：图标 + 一句话 + （可选）主按钮，垂直居中。
- **等宽场景**（计算式/时间戳/JSON/代码）：`ui-monospace, SFMono-Regular, Menlo, Consolas, monospace`。

## 3. 计算稿纸（calc）像素级专项 — 照 `refs/calc-paper-utools.png`

结构从上到下：
1. **插件标题栏** 40px：左「← 计算稿纸」，右侧溢出菜单（⋮）与 Logo 位。
2. **行区**（核心）：每行高 ~34px，横向布局 = 行号（`--fs-foot` 等宽，`--fg-dim`，右对齐 24px 宽）+ 表达式输入（等宽字体 `--fs-title`，透明底，无框）+ 右侧结果（等宽，右对齐，`--fg`，字号同表达式，结果与表达式间以足够留白分隔）。
3. 行为细节：
   - 当前行（焦点行）：整行 `--hover` 底色；行号变 `--accent`。
   - 回车 = 计算并在下一行新建空行；↑↓ 在行间移动；行内容删除到空再退格 = 删行。
   - 行悬停：行尾出现删除按钮（×，`--fg-dim`，hover 变 `--danger`）。
   - 表达式非法：该行结果位置显示红色 `--danger` 短提示（如 `无效表达式`），不弹窗。
   - 支持行间变量引用（`a = 12` 之后的行可用 `a*2`），支持 `+ - * / % ^ ()` 与常用函数（sqrt/sin/cos/round…，量纲从简）。
   - 合计：行区底部一条合计行（分隔线上方，加粗，右侧显示 Σ 结果）。
4. **顶部工具**（放标题栏右侧或行区上沿）：清空全部（需二次确认，用行内确认而非弹窗）、复制结果、历史记录下拉。
5. 配色：整体浅色白底；如参考图含强调色（橙色系 Logo/标记属 uTools 品牌），GTools 用 `--accent` 代替，不引入新品牌色。

## 4. 各插件页面布局要点（功能合理 + 视觉对齐 uTools 同类插件）

| 插件 | 布局要求 |
|---|---|
| file-search 本地搜索 | 结果列表复用 §1.4 行样式：文件名主文 + 路径次文灰色截断 + 类型徽标；顶部一行来源提示（Spotlight/目录扫描）；空态引导输入关键词 |
| clipboard 剪切板 | 顶部分类 tab（全部/文本/链接/图片/文件）+ 搜索框；条目卡片：内容预览（两行截断，图片缩略 48px）+ 右下时间与来源应用；hover 浮出 复制/固定/删除 按钮组；固定条目置顶带 📌 徽标 |
| pdf-tools | 左右两栏：左文件列表（拖拽区 + 已加入文件卡片，可排序）+ 右操作面板（合并/拆分/旋转/删页/提取/图片转 PDF，选中操作后参数区 + 执行按钮 + 结果导出）；进度与错误用页面内状态条，不弹窗轰炸 |
| translate 聚合翻译 | 左右双栏各占一半：左源文（多行输入，底部语种选择 + 清空 + 粘贴）右译文（结果 + 复制 + TTS 发音按钮）；顶部引擎切换（配置中心已启用的引擎 tab）；交换按钮居中 |
| markdown-notes | 左侧笔记列表（标题 + 摘要 + 时间，当前选中高亮）+ 右侧编辑区（编辑/预览 tab 或分屏，工具栏：新建/删除/导出 .md）；无笔记时空态 |
| todo-pomodoro | 上半任务列表（勾选圆圈 + 文案，完成划线置灰，优先级色点）+ 底部添加行；右侧或下方番茄钟卡：大号倒计时（等宽 32px+）+ 开始/暂停/重置 + 今日完成计数 |
| memo 备忘快贴 | 单列便签流：每条卡片 = 文本 + 时间，hover 浮出 复制/置顶/删除；顶部快速输入行（回车即存）；置顶分组在上 |
| float-image 悬浮 | 主页面：选择/拖入图片 + 已悬浮列表（缩略图 + 位置/尺寸记忆）+ 「新建悬浮窗」；悬浮小窗本体：无边框、hover 底部浮出控制条（放大/缩小/透明度滑杆/关闭） |
| time-toolbox | 分区块卡片：① 当前时间多格式（等宽，点击复制）② 时间戳→日期（输入即转，秒/毫秒自动识别）③ 日期→时间戳 ④ 相对时间计算（N 天前/后）⑤ 常用时区对照表 |
| json-editor | 左编辑（等宽 textarea，行号槽可选）右树视图（可折叠节点）；顶部工具：格式化/压缩/校验/复制/示例；校验错误行内提示（错误行号 + 原因，红色下划线或状态条）；支持大 JSON 不卡（树视图懒渲染） |
| json/diff 等已有页面 | 不在本期 11 个之列的插件不动，只保证新 tokens 不破坏其显示 |

## 5. 验收

- 每个页面以 800×600（必要时可 800×N）截图，与参考图/本规范逐项核对：布局结构、层级底色差、圆角、字号、间距、三主题（至少 light 必验，dark/glass 抽验）。
- 截图产物 `.zcode/screenshots/<pluginId>.png`；shell 空态 `shell-empty.png`、搜索态 `shell-query.png`。
- 功能合理性：交互闭环（有入口、有反馈、错误可恢复）、无假按钮、无占位文案。
